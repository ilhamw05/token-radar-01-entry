How the radar prices a launch

Every implied value on this board is one multiplication, computed from the snapshot itself: implied value = TVL × category multiple × growth factor × maturity factor. The category multiple is the median market-cap/TVL of the already-listed protocols in the same category in this snapshot — the price the market already pays for a dollar of TVL there — falling back to the overall live median when a category has fewer than three listed peers. The growth factor reads the protocol's 7-day TVL change; the maturity factor reads how long DefiLlama has tracked it with no token recorded. No name is priced by hand: one function scores every row, and each protocol's page shows its own arithmetic.
